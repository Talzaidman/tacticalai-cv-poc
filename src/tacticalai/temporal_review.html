What was measured

Same saved YOLO26s / TrackTrack observations, source buffer 30, ReID enabled with the original generic encoder, GMC sparseOptFlow. No detector or tracker rerun. The new offline layer uses basketball-trained CLIP-ReIdent features, persistent appearance-change checks, and one-to-one gallery matching. The selected buffer 45 applies to future tracker runs.

Development thresholds were assessed using these clips and your feedback. This is not an independent accuracy benchmark. Only one change per raw ID is supported in this experiment; pose changes, small crops and occlusion can still cause errors. Missing detections and off-screen positions are not invented.
